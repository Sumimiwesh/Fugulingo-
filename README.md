# 🐡 Fugulingo (フグリンゴ)
### 飲食店アルバイト向け ホール業務マイクロラーニングWebアプリ

「Fugulingo」は、飲食店の新人アルバイトスタッフが現場で必要とされる接客マナー、ご案内、配膳、クレーム一次対応などのホール業務基準を、Duolingo風の楽しいステップUIで効率的に習得できるマイクロラーニングWebアプリケーションです。

**✨ 完全APIキー不要・ゼロコンフィグ仕様**:
外部AIサービスのAPIキー取得や入力などの煩わしい設定は一切不要です。起動した瞬間から、マニュアルからの4択問題自動生成、クイズ学習、カレンダー記録、修了証のPNG出力など、すべての機能が快適に動作します。

---

## 🌟 主な特徴 & コア機能

### 1. 🎨 洗練されたミニマルUI & カラーパレット
- **メインアクセント**: `#AFDFE4`（爽やかなペールミント/シアン）
- **ベース/背景**: `#FFFEF6`（目に優しいオフホワイト/アイボリー）
- **文字/ボーダー**: 落ち着いたチャコールグレー系（`#2C3437`, `#5C676C`, `#E2E8F0`）
- **モバイルファースト**: スマートフォンでの片手操作に最適化しつつ、PC表示時も中央コンテナで崩れないレスポンシブ設計。画面左上には円形PNGロゴのプレースホルダーを配置。

### 2. 🔐 ロール別アクセス制御（Role-based Access）
Firestoreの `users` コレクション内の `role: "admin" | "staff"`、または管理者メールアドレス照合によって画面・操作を完全分離：
- **アルバイト画面（staff）**:
  - 学習ツリー（ホーム）での4択クイズ解答
  - 連続学習日数（ストリーク）カレンダー確認
  - 獲得した修了証（横向きA4 / PNGダウンロード）の閲覧
- **管理者画面（admin）**:
  - ホールマニュアル登録（PDF/画像/自由記述テキスト）
  - 4択問題の自動生成・編集・承認・公開（APIキー不要）
  - マニュアルの版管理（旧版への変更/アーカイブ、およびワンクリックでの旧版復元）
  - ※画面右上および設定画面から、いつでもワンタップで「アルバイト ↔ 管理者」を切り替え可能です（テスト・審査用）。

### 3. ⚡ 内蔵インテリジェント問題自動生成（APIキー完全不要）
マニュアルのテキストやシチュエーションを解析し、以下のルールに沿った高品質な4択問題をワンクリックで瞬時に自動生成：
- **出題ルール徹底遵守**:
  - ホール業務の実践的なシチュエーション問題
  - 明らかに正解とわかる選択肢を排除し、新人が間違えやすい「リアリティのあるひっかけ」を含める
  - 4つの選択肢の文字数を均等に揃える
  - 正解時の解説、および求められる「接客マインド・ホスピタリティスキル」のフィードバック文を含める
- 生成された問題はその場でプレビュー・インライン編集が可能。管理者の「承認して公開」ボタンで即座に学習ツリーへ反映されます。

### 4. 🦉 デュオリンゴ風 縦型学習ツリー & クイズ画面
- S字状に配置された縦型ステップUI（①、②、③...）。
- セクションごとに確認テスト（チェックポイント）を配置。合格（80%以上正解）すると次のステップが解放。
- 解答時は即時フィードバック（正解/不正解判定、ひっかけの罠、解説、接客マインド）。

### 5. 👥 Googleアカウント個別保持 & 仲間たちの学習記録（モチベーション機能）
- **Googleログイン**: Firebase Auth による Google ポップアップログインに対応。ログインしたユーザーそれぞれが自分のストリーク日数、クイズ進捗、獲得修了証をクラウドに安全に個別保持できます。
- **連続学習ランキング**: 店舗の仲間たちがどれくらい継続して学習しているか（ストリーク日数、累計クリア問題数）をトップ3表彰台とともに可視化。
- **応援タイムライン（拍手インタラクション）**: 仲間が確認テストに合格したり修了証を獲得した際にリアルタイムでアクティビティが共有され、「ナイス！👏」で応援し合えます。

### 6. 🔥 連続学習記録（ストリークカレンダー）
- 日々の解答数、正解数、完了ステップ数を記録。
- 月間カレンダーUIで学習した日をハイライト表示し、継続意欲を高めます。

### 7. 📜 デジタル修了証（横向きA4比率 & PNG書き出し）
- セクションの全問クリアで修了証を発行。
- 横向きA4比率（`1.414 : 1`）のミニマルな和モダン証書デザイン（受講者名、受講日、セクション名、認定印、証明書番号）。
- `html2canvas` により、ワンクリックで高解像度PNG画像としてダウンロード可能。

### 8. 📚 マニュアルの版管理（バージョンコントロール）
- マニュアル差し替え時は既存データを削除せず「アーカイブ（非アクティブ）」状態に変更。
- 管理者画面のバージョン履歴からワンクリックで「旧バージョンの復元（アクティブ化）」が可能。

## 🛠 技術スタック & アーキテクチャ

| レイヤー | 技術 |
|---|---|
| **フロントエンド** | React 19, TypeScript, Vite, Tailwind CSS |
| **アイコン & 演出** | Lucide-react, Canvas Confetti |
| **画像生成** | html2canvas (横向きA4修了証のPNG出力) |
| **問題自動生成** | 内蔵インテリジェント問題生成エンジン (完全キーレス・オフライン完結) |
| **インフラ / DB** | Firebase Sparkプラン (完全無料枠, Cloud Functions不使用の完全サーバーレス) |
| **認証** | Firebase Authentication (Googleログイン & 即時デモ切り替え) |
| **データベース** | Cloud Firestore (`users`, `manuals`, `sections`, `userProgress`, `userStreaks`) |
| **ストレージ** | Firebase Storage (マニュアルPDF/画像, 修了証アセット) |

> **疎結合設計（ネイティブアプリ化への配慮）**:
> データ永続化や認証ロジックは `src/services/`（`dataService.ts`, `quizGeneratorService.ts`, `authService.ts`）および `src/context/` に集約。Web特有のwindowオブジェクト等への依存を最小限に抑えているため、将来的に **Capacitor** や **React Native** でネイティブアプリ化する際もコードをそのまま流用可能です。
> また、Firebase未設定時でもローカルストレージ自動フォールバックが働くため、環境変数を設定しなくても即座にフル機能が動作します。

## 🚀 起動方法

### 1. 開発サーバーの起動
```bash
npm run dev
```

### 2. プロダクションビルド
```bash
npm run build
```

環境変数やAPIキーの入力は一切不要で、すぐにブラウザで全機能をお試しいただけます。
